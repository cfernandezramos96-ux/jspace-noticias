ElKazuoTV Uploader

ElKazuoTV Uploader is a private, internal tool used by the creator of the YouTube channel ElKazuoTV to upload his own finished Shorts (Japanese music and anime content) to his own channel.

Uses YouTube API Services

What it does

  • Uploads videos that the channel owner made himself to the ElKazuoTV channel, using the YouTube Data API v3 (videos.insert).
  • Sets the title, description, tags, category and privacy status of those uploads.
  • Reads basic information about the owner's own channel to confirm it is uploading to the right place.

Who can use it

Only the owner of the ElKazuoTV channel. The tool is not offered to the public, has no other users and does not access any other person's YouTube account or data. It runs on the owner's own computer.
